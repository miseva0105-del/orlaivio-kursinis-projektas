AMPHIBIOUS AIRCRAFT MISSION AND SPECIFICATIONS DEMONSTRATOR

Open index.html in your browser. Keep app.js next to it.
Use the stage navigation to follow the 15 steps, numbered 0 through 14.
Open the reference aircraft database from the toolbar. Use Save JSON for
a portable backup, or export the aircraft and source tables as CSV files.

Upload Amphibious_Aircraft_Mission.ipynb into Google Colab. Save your own copy
and run the cells in order. The optional database import is off by default.
The results folder contains example CSV tables, report text and PNG/SVG plots.

The ICON A5 is a reference aircraft. The 120 km flight distance, cruise
altitude and other model inputs are teaching assumptions. The model is
kinematic and aircraft performance requires separate verification.

For static web hosting, upload index.html, app.js and the notebook together.
